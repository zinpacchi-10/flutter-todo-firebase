# Flutter Task Management App

A clean and modern **Task Management / Todo App** built with **Flutter** + **Firebase**.  
Supports real-time data sync, user authentication, and works on both Android & iOS from a single codebase.

## ✨ Features

- Email/Password Authentication (Firebase Auth)
- Real-time Task CRUD with Cloud Firestore
- User-specific Tasks (each user only sees their own data)
- Add, Edit, Delete & Mark as Completed
- Priority support
- Loading states, Error handling & Snackbars
- Clean & Responsive UI
- Splash Screen + Custom App Icon
- Works on both Android and iOS

---

## 🛠️ Tech Stack

- **Framework:** Flutter + Dart
- **Backend:** Firebase
  - Firebase Authentication
  - Cloud Firestore
- **State Management:** Provider / setState
- **Other:** Shared Preferences (optional)
